# Provenance

Adapted from the system prompts and MCP tool reminders of
[Dataojitori/nocturne_memory](https://github.com/Dataojitori/nocturne_memory),
originally copyright (c) 2025 Salem, under the MIT license.

This skill rewrites those ideas for the current Rust `nocturne` CLI: scoped user
authorization, evidence-first retrieval, safe content updates, shared-node identity,
and cross-platform file-based workflows. It does not preserve the legacy persona,
automatic persistence, mandatory startup protocol, or MCP interface as instructions.
Current adaptations are copyright (c) 2026 lll9p. The full notices and MIT terms are
included in this skill's LICENSE.

All operational references ship inside this directory; the upstream runtime is not
required. Skill installation through
[vercel-labs/skills](https://github.com/vercel-labs/skills) is independent of installing
the CLI and selecting or initializing a database; it grants no command permissions.
